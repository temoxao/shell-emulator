# Shell Emulator
Консольный эмулятор командной оболочки ОС, разработанный в рамках практической работы.

На первом этапе реализован минимальный прототип с интерактивным консольным интерфейсом (CLI). Эмулятор формирует приглашение к вводу на основе данных операционной системы, поддерживает раскрытие переменных окружения и предоставляет команды-заглушки `ls` и `cd`, а также команду `exit`.

## Функции

### Командный интерфейс

Программа работает в интерактивном режиме и ожидает ввод команд пользователя.

### Приглашение командной строки

Приглашение формируется на основе имени пользователя и имени компьютера, полученных из операционной системы.

Пример:

```
username@hostname:~$
```

### Раскрытие переменных окружения

Программа поддерживает раскрытие переменных окружения в аргументах команд.

Например:

```
ls $HOME
```

переменная `$HOME` заменяется на значение переменной окружения `HOME`.


## Запуск

Для запуска эмулятора необходимо выполнить команду:

```
python3 src/main.py
```

После запуска программа переходит в интерактивный режим и ожидает ввода команд.

## Тестирование

На первом этапе автоматические тесты не реализованы. Работоспособность прототипа проверяется в интерактивном режиме.

Для запуска программы используется команда:

```
python3 src/main.py
```


## Пример использования

После запуска программы можно вводить команды в интерактивном режиме.

Пример:

```
tim@MacBook-Air-Timofej-2.local:~$ ls hello test
ls hello test
ls hello test

tim@MacBook-Air-Timofej-2.local:~$ cd test
cd test
cd test

tim@MacBook-Air-Timofej-2.local:~$ ls $HOME
ls $HOME
ls /Users/tim

tim@MacBook-Air-Timofej-2.local:~$ exit
exit
```
## Команды

### `ls`

Команда-заглушка `ls` выводит свое имя и переданные аргументы.

### `cd`

Команда-заглушка `cd` выводит свое имя и переданные аргументы.

### `exit`

Команда `exit` завершает работу эмулятора.
